Features

What each system does

Everything is configured from the in-game menu (INSERT) and saved to your settings file, so your setup survives restarts.

Aimbot

Runs on its own thread instead of waiting for the next drawn frame, so it reacts as soon as a target is valid.

  • Low-latency targeting — picks the closest valid enemy to your crosshair.
  • Smoothing control — from instant snap to slow, human-looking pulls.
  • FOV circle — only targets inside the circle are considered; draw it on screen or keep it hidden.
; aimbot
enabled    = true
key        = F6
fov        = 4.0
smoothing  = 0.62
draw_fov   = true

ESP

A transparent overlay that draws player information on top of the game window.

  • Skeleton bones — full bone outline, so you can read stance and direction.
  • Snaplines — a line from the screen edge to each player.
  • Health bars — current HP next to each player.
  • Player names — with separate colours for teammates.
; visuals
key        = F1
skeleton   = true
snaplines  = false
health_bar = true
names      = true
teammates  = true

Recoil Control

Pulls your aim against the weapon's spray so the first bullet and the twentieth land in the same place.

  • Spray pattern compensation — counters vertical climb and horizontal drift.
  • Weapon profiles — different strength per weapon, so rifles and SMGs feel right.
; recoil
enabled    = true
strength   = 85%
; per-weapon
ak47       = 90%
m4a1_s     = 80%

Bunnyhopping

Hold the key and VANTA jumps the moment you touch the ground. Let go and you're back to normal movement.

  • Automatic jump timing — fires on landing, no scroll-wheel binds needed.
  • Movement assist — keeps your speed through chained hops.
  • Any key — Space by default, rebindable in the Keybinds tab.
; movement
bunnyhop   = true
mode       = hold
key        = SPACE

Bomb Timer

Real-time bomb information overlaid on screen, updated every frame so you never miss the countdown.

  • Live countdown — seconds remaining until detonation.
  • Distance to bomb — how far you are from the C4 in meters.
  • Defuse viability — shows if you can defuse in time with or without a kit.
  • Travel time — calculated at ~6.35 m/s movement speed.
; bomb timer
enabled    = true
key        = F3
show_distance = true
show_status = true

Questions

How do I activate my code?

After payment the admin sends you a code. Run VANTA, paste the code into the activation screen, and the menu unlocks. The code works on one PC.

What happens when my term ends?

The app asks for a new code on next launch. Your settings file is kept, so a renewal picks up exactly where you left off.

How do updates work?

CS2 updates can break things. When that happens a fixed build is posted on the Download page and announced in Discord. Download it and replace your old file — your code still works.

Can I get banned?

Yes. Any third-party program that reads the game's memory carries a risk of a VAC or Overwatch ban, and no tool can promise otherwise. Only use VANTA on an account you are prepared to lose.
